# Jevに共通テスト（センター試験）解かせてみた

[OpenRouter](https://openrouter.ai/) の決定特化モデル **JEV**（`typesafe/jev-1.13`）に、
東大ロボットプロジェクトが公開しているセンター試験の電子化問題を解かせてみた記録です。
1990〜2017年度の本試験・追試験、11科目、**17,215問**を1問ずつ採点しました。

JEVはテキスト専用で画像を入力できません。図は本文中に `［図 ファイル名］` という
プレースホルダとして残したまま解かせています。つまり「図が見えない状態での実力」の計測です。

全科目合計では **17,215問中13,892問正解、正答率80.7%**。配点で重み付けした得点率も80.3%でした。

## 各科目の正答率

| 科目 | 全体の正答率 | 図なしの正答率 | 図ありの正答率 |
| --- | --- | --- | --- |
| 倫理 | 92.4% | 93.3% | 72.7% |
| 世界史 | 89.2% | 91.5% | 86.0% |
| 政治経済 | 88.1% | 91.6% | 45.6% |
| 現代社会 | 86.7% | 88.7% | 51.3% |
| 地学 | 86.1% | 93.6% | 76.0% |
| 生物 | 81.6% | 85.8% | 77.1% |
| 化学 | 79.2% | 83.9% | 52.8% |
| 地理 | 78.8% | 88.1% | 71.4% |
| 日本史 | 76.1% | 78.2% | 68.3% |
| 英語 | 74.1% | 75.0% | 66.8% |
| 物理 | 56.0% | 77.1% | 51.0% |

全体では図なしが85.4%、図ありが70.2%で、**15ポイントの差**がつきました。図があるだけで
正答率が落ちるというより「図の中身を読めないと解けない問題は落とす」という素直な結果です。

物理の落ち込みが顕著で、図なしなら77.1%取れているのに全体では56.0%まで下がります。
物理は選択肢そのものが数式の画像になっている問題が多く、図以前に選択肢が読めません。
逆に世界史は図ありでも86.0%と健闘していて、図が補助的な資料に留まっている科目は
画像がなくても戦えることがわかります。図ありの問題数が少ない科目（現代社会76問・倫理33問・
政治経済79問）は数字が振れやすいので参考値として見てください。

## コストと速度について

| 項目 | 値 |
| --- | --- |
| リクエスト数 | 3,054（大問ごとに1リクエスト） |
| 総費用 | **$0.316**（約47円） |
| 1問あたり | $0.000018 |
| 1科目1年度あたり | $0.00053（約0.08円） |
| トークン | 入力7,519,683 / 出力813,665 |
| 実行時間 | **3分17秒**（並列8） |
| 1リクエスト | 平均0.51秒 / 中央値0.49秒 |

費用はOpenRouterのレスポンスに入っている `usage.cost` をそのまま合計した実測値です。
3,054リクエストすべてで返ってきました。1科目1年度（1試験ぶん）を丸ごと解かせても
0.1円未満で、採点対象外の問題も含めた21,234問すべてを解かせても60円弱です。

安い理由は**大問ごとにリクエストをまとめている**からです。JEVのAPIは `state`（本文）と
`questions`（設問の集合）を分けて渡す設計なので、大問のリード文を小問の数だけ
再送する必要がありません。1問1リクエストで投げていた頃は1問あたり$0.000033だったので、
約45%安くなりました。

速度も実用的で、1リクエスト0.5秒前後。並列8なら全データでも5分かかりません。
途中で止めても同じコマンドで続きから再開できるので、時間のかかる実験でも回しやすいです。

## おまけ：JEVはどれくらい自信を持って答えているか

`choice` のレスポンスには選択肢ごとの確率分布が入っています。予測は最も確率が高い選択肢です。
正解した問題について「正解の確率 ÷ いちばん高い誤答の確率」の中央値を取ると **15.2倍**でした。
ただし図ありの問題では **2.38倍**まで下がります。画像が読めない問題では、当てはしても
薄い自信で選んでいるということです。

1位と2位の確率差で分けると、差が0.6以上の問題は96.4%正解、0.1未満だと36.4%でした。
確率が拮抗している問題は実際に落としているので、確信度は精度と素直に対応しています。

## まとめ

画像を入力できないJEVにセンター試験を解かせると、全体で80.7%でした。図のない問題なら
85.4%、図がある問題は70.2%。**画像が使えないハンデはおよそ15ポイント**で、科目によって
その影響は大きく違います。現代社会や政治経済のように図の1枚が正誤を決める科目では
20〜40ポイント落ちる一方、世界史のように図が補助的な科目はほとんど影響を受けませんでした。

費用と速度は実用範囲です。1試験あたり0.1円・数秒で、全21,234問でも60円弱・5分以内。
テキストだけのベンチマークとしては十分回せる規模感で、画像を扱えるモデルと比べたときの
差分を測る土台になりそうです。

なお採点対象は21,234問のうち17,215問です。複数解答欄や複数正解、記号解答の問題は
正解を選択肢1つに還元できないため除外しました。数学も同じ理由で対象外です。

## このリポジトリで試すには

問題データは同梱していません（著作権は大学入試センターにあり、配布元も商用利用を
断っているため）。以下から各自ダウンロードしてください。

**データ入手元**: https://21robot.org/dataset.html

「ロボットは東大に入れるか」プロジェクトが公開しているセンター試験XMLデータです。
研究目的での利用に限られます。

| 入手するもの | URL |
| --- | --- |
| 開発用データ | https://21robot.org/data/center-dev.tar.gz |
| 開発テスト用データ | https://21robot.org/data/center-devtest.tar.gz |
| 最終テスト用データ | https://21robot.org/data/center-finaltest.tar.gz |
| 正答データ | https://21robot.org/data/center-answer.tar.gz |
| 数学・物理用DTD | https://21robot.org/data/torobo-math-dtd.tar.gz |

**配置**: 展開してこのリポジトリの直下に置けば、`jev_eval.py` が既定のパスを見ます。

```
jev-center/
├── jev_eval.py
├── center-finaltest/center-finaltest/          # 問題XML（--split finaltest）
└── torobo-data/extract/
    ├── center-dev/center-dev/                  # --split dev
    ├── center-devtest/center-devtest/          # --split devtest
    └── center-answer/center-answer/            # 正答データ（split ごとに分割）
```

**実行**:

```bash
echo OPENROUTER_APIKEY=sk-or-... > .env

python jev_eval.py --dry-run             # APIを叩かず対象件数と概算費用を確認
python jev_eval.py --simulate --limit 20 # APIを叩かず集計処理だけ動作確認
python jev_eval.py --workers 8           # 全データを実行（既定で3分割すべて）
```

追加ライブラリは不要で、Python 3.11の標準ライブラリだけで動きます。
主なオプションは `--subjects Chiri,Chigaku`（科目を絞る）、`--split finaltest`（分割を絞る）、
`--text-only`（図を参照する小問を除く）、`--official-scores official.json`（実際の平均点・
標準偏差を渡すと偏差値も出す）です。結果は `results/jev_sections.jsonl`（1大問1行）と
`results/jev_sections.summary.json` に保存され、途中で止めても同じコマンドで続きから走ります。
